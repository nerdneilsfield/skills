# 论文精读

默认用三轮帮助读者从整体认识走到方法理解和证据评估。使用中文，保留必要的英文术语和公式；讲解具体、直接，避免重复总结和机械套用模板。

## 先取得可读的论文内容

收到 PDF 附件、本地路径或 PDF 链接时，先完成解析，再开始精读；不能假定当前 agent 能直接读取 PDF。

1. 查看当前环境的技能列表，找到支持 PDF 文本提取、页面渲染或 OCR 的技能（例如 `pdf`、`pdf:pdf` 或同等能力的技能）。先读取其 `SKILL.md`，按其指引调用工具解析论文，不只在回复中建议使用。技能名称和路径以当前环境为准，不依赖固定机器路径。
2. 取得可检索的正文并保留页码、章节、图表编号与图注；确认标题、版本，以及正文和附录的覆盖范围。扫描版或文字提取为空、乱码、阅读顺序异常时，按 PDF 技能提供的方法使用 OCR 或页面渲染补救。
3. 抽查关键页面的提取质量，特别是双栏顺序、公式符号、表头和数值。图表深读前通过该技能渲染相关页面或提取图像，并使用可用的图像查看能力检查；纯文本提取不能替代图表阅读。公式损坏时回看页面，不凭上下文补造。
4. 复用已取得的文本和页面，按当前轮次读取必要部分，避免每轮重复解析。用户已提供可靠的解析文本或 HTML 全文时可直接使用；缺失图表或公式时再补取对应 PDF 页面。

没有可用的 PDF 技能时，检查现有工具能否完成文本提取和必要的页面查看，或取得同一版本的 HTML/全文。仍无法取得正文时，请用户提供解析后的 Markdown、文本或必要页面；明确能力缺口，不声称已解析。仅能读取部分材料时说明覆盖范围，只分析可验证的内容。

解析属于第一轮前的准备工作，不单独占一轮，也不要求用户回复“继续”才开始解析。

## 开始与节奏

- 先检查论文是否可读取，确认标题、版本和可用材料。只有摘要或部分正文时，限定分析范围，不声称已阅读全文、附录或代码。
- 用户未说明背景和目的时，默认具备基础专业知识、以理解论文为目标，直接开始第一轮。只有缺少论文等必要材料时才提问。
- 每次只输出当前轮，用户回复“继续”后进入下一轮；支持跳转、合并或深入指定问题，以用户指令为准。
- 后续轮次引用前文即可，不重复已讲清的内容。前两轮末尾只用一句话提示下一轮，然后停止；第三轮完成后不强制追加流程。
- 根据目的调整重点：复现侧重实现和验证，综述侧重研究关系，审稿侧重主张与证据，落地侧重成本与边界。

## 第一轮：问题与整体认识

用较短篇幅讲清：

1. 一句话概括论文。
2. 要解决的问题、为什么重要，以及已有方法的主要不足。
3. 核心思路与实际贡献：相对已有工作具体改变了什么。
4. 最关键的结果及其适用条件，初步区分作者声称与证据支持的范围。
5. 推荐优先阅读的章节和图表，以及需要带到下一轮核查的问题。

本轮建立整体认识，不展开完整公式推导和逐项实验分析。

## 第二轮：方法与证据

围绕核心方法和证据展开：

1. 用“输入 → 关键步骤 → 输出”解释整体流程，再拆解必要模块。
2. 解释关键公式或机制：符号含义、设计动机、作用；必要时给小例子。
3. 选择最关键的 3–5 张图表（不足时按实际数量），结合方法或实验讲解实际展示的内容、支持的结论，以及解释边界和比较条件。
4. 检查数据集、指标、基线、计算预算和消融，判断比较是否公平、证据是否充分。
5. 对照最相关的工作，说明真正的差异与代价。

阅读图表时查看实际图像或表格，依据图注、坐标轴、图例、表头、单位和数值解释。只能取得图注时说明限制；无法清晰辨认的数值标为不确定。不要求逐图复述，也不机械打分。

## 第三轮：局限、应用与复现

在前两轮基础上深入评估：

1. 最可靠的结论，以及尚未得到充分支持的主张。
2. 关键假设与可能的失败场景，说明依据和假设失效的后果；区分已观察到的失败与推测。
3. 实际应用约束，如数据、算力、延迟、鲁棒性和适用范围。
4. 最小复现路径：所需材料、关键设置、验证步骤和成功标准。仅在有助于重建方法时给伪代码；不补造超参或实现细节，也不把复现方案称为已完成复现。
5. 提出 2–3 个值得继续探索的问题，说明如何验证、可能收益与风险。

按论文类型取舍：理论论文侧重命题条件、证明关键步骤和反例，不强行套用训练、部署或实验清单。

## 证据与核验

- 关键结论标注论文位置，如章节、图表或公式编号；无法定位时明确说明，不编造。
- 区分作者主张、论文证据和分析推断。解释必要的推导步骤与判断依据；缺失信息标为“未报告”或“待核验”。
- 重要术语首次出现时简要解释；仅在确有必要时补充小型术语表。
- 复述论文自身的方法和结果时，引用论文位置即可。涉及外部事实或时效性判断，如发表版本、代码可用性、相关工作和当前 SOTA 时，按需联网核验。
- 优先使用原始论文、正式出版页、官方仓库和数据集主页；关键争议再交叉核验，不强制每条信息凑两个来源。
- 核验结果就近附可访问链接；来源冲突时说明版本、时间或评测条件差异。无法联网或查证时明确标注，不把未核验的信息写成确定事实。

## 按需扩展

仅在用户要求时展开完整术语表、全部图表索引、逐公式推导、详细复现方案或引用逐条校对。长内容可分批输出，不把这些扩展变成默认阅读的前置步骤。
